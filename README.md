# 젤리몬! (JellyMon) — v1.0 50레벨 캠페인

빠지냥(Drop the Cat)과 같은 게임 방식:
**다양한 모양·색상의 구멍 블록(캐처)을 드래그로 움직여서, 같은 색 젤리를 흡수(가두기)한다.
다른 색 젤리는 통과할 수 없는 장애물이고, 캐처끼리도 통과할 수 없다.**

## 실행 방법

1. [Godot 4.4 이상](https://godotengine.org/download) 설치 (Standard 버전, .NET 불필요)
2. Godot 프로젝트 매니저 → **가져오기(Import)** → 이 폴더의 `project.godot` 선택
3. 에디터에서 **F5** (또는 우상단 ▶) 로 실행
4. 데스크톱에서는 마우스 드래그 = 터치 드래그 (터치 에뮬레이션 켜져 있음)

## 게임 규칙 (v0.3 코어 — 사용자 확정 룰)

- **캐처(구멍 블록)를 드래그**하면 격자 단위로 슬라이드
- 캐처가 지나가는 자리의 **같은 색 젤리는 즉시 흡수**(구멍 속으로 쏙!)
- **다른 색 젤리는 통과 불가** — 다른 색 캐처로 먼저 길을 뚫어야 함 (순서 퍼즐)
- **캐처끼리 통과 불가**, 벽(`#`) 통과 불가
- 캐처의 숫자는 **남은 수용량**. 같은 색 젤리를 숫자만큼 흡수하면 캐처가 사라져 새 길이 열림
- 모든 젤리를 흡수하면 클리어. 제한시간 초과 시 실패(재도전 무료·무제한)
- 캐처 모양: 1×1, 2×1, 1×2, 3×1, 2×2, L자 2종 — 넓적한 캐처는 한 번에 여러 마리 흡수

## 차별화 요소 (빠지냥 대비)

| 요소 | 내용 |
|---|---|
| 샤이니 젤리 | 2% 확률 등장, +500점, 반짝임 연출 |
| 가두기 이펙트 | 아래 상세 — 손맛 중심 설계 |
| 스트레스 완화 | 라이프 없음, 실패 시 즉시 무료 재도전 |
| 접근성 | 모든 젤리·캐처에 색상별 고유 무늬(♥★●▲◆✿) — 색약 대응 |
| 햅틱 | 모바일에서 흡수·홀 제거 이벤트마다 진동 |

### 가두기(흡수) 이펙트 구성
젤리 스쿼시 → 캐처 구멍 속으로 회전하며 빨려드는 트윈(0.16s) → 색상 방울 파티클 버스트 + 소용돌이 입자 + 충격파 링 → 캐처 "꿀꺽" 스쿼시 → 플로팅 점수 → 햅틱. 한 번에 3마리 이상 쓸어담으면 화면 셰이크.

## 레벨 구성 (50개)

- L1~4 — 조작과 색 장벽을 배우는 쉬운 튜토리얼
- L5~10 젤리 마을 — 다칸 캐처, 좁은 문, 겹층 순서 퍼즐
- L11~20 캔디 숲 — 소용량 다중 홀, 행·열 교차 배치와 불규칙 외곽
- L21~30 소다 해변 — 4색, 링/체커 레이어 순서 퍼즐
- L31~40 아이스 설산 — 더 큰 보드와 높은 장애 밀도
- L41~50 초코 화산 — 최대 5색, 복합 패턴, 챕터 최종 관문

홀 모양은 L1~4 튜토리얼 이후 테트리스의 7개 테트로미노를 기준으로 구성된다.

- L1~4: 조작 학습용 1×1, 2×1, 1×2
- L5~10: I·O 테트로미노
- L11~20: J·L 및 회전형 추가
- L21~30: T와 네 방향 회전형 추가
- L31~50: S·Z와 회전형까지 7종 전체 혼합
- 제한시간은 L5 90초부터 점차 줄어 L50에서 63초가 되어 제거 순서를 빠르게 판단해야 함
- 홀은 상·중·하단에 분산하고 젤리를 홀 주변 빈칸으로 재배치해 두 종류가 보드 전체에서 뒤섞임
- 재배치된 다른 색 젤리가 대형 홀의 이동 통로를 막아 올바른 제거 순서를 요구함
- L5부터 10종의 외곽 변형(계단·좌우 홈·중앙 홈·비대칭 모서리)을 레벨마다 순환 적용
- 큰 블록의 마지막 목표가 모서리에 고립되지 않도록 자동 젤리 재배치에서 외곽 셀을 제외

레벨 선택 화면은 챕터별 10레벨을 묶은 세로 스크롤 맵이며, 이전 레벨을
클리어하면 다음 레벨이 열린다. 모든 레벨은 실행 시 행 길이, 캐처 시작점,
색상별 캐처 존재 여부와 실제 이동 충돌 기준 도달 가능성을 자동 검사한다.

개발용 빠른 레벨 검증:

```bash
/Applications/Godot_mono.app/Contents/MacOS/Godot --headless --path . -- --validate-levels
```

## 후속 확장 범위

- 특수 젤리: 무지개·폭탄·풍선·돌·왕젤리(보스)
- 바닥 타일: 포털·얼음·진흙
- 부스터, 코인 경제/도감/상점, 광고·IAP
- BGM, 일시정지 팝업, 설정(사운드/햅틱 토글)

## 폴더 구조

```
game/
├── project.godot        # Godot 4.4+, 720×1280 세로, 터치 에뮬레이션
├── scenes/Main.tscn     # 루트 씬 (나머지는 코드로 구성)
├── scripts/
│   ├── Main.gd          # 화면 전환/저장
│   ├── Game.gd          # 코어 룰 (캐처 이동/흡수/용량 제거)
│   ├── Catcher.gd  Jelly.gd  FX.gd  HUD.gd
│   ├── Levels.gd        # 50레벨 생성·검증 데이터
│   ├── Title.gd  Map.gd  AudioMgr.gd  SaveGame.gd  G.gd
├── assets/
│   ├── catchers/        # 캐처(구멍 블록) 스프라이트 (7모양×6색)
│   ├── jelly_*.png      # 젤리 + UI 아이콘
│   └── fonts/Jua-Regular.ttf  (OFL 라이선스, OFL.txt 동봉)
└── audio/               # 프로그래매틱 생성 효과음 (WAV)
```

에셋은 전부 자체 생성물이라 라이선스 문제 없음 (폰트는 SIL OFL).
