# 젤리몬! (JellyMon) — v1.2 500레벨 캠페인

빠지냥(Drop the Cat)과 같은 게임 방식:
**다양한 모양·색상의 구멍 블록(캐처)을 드래그로 움직여서, 같은 색 젤리를 흡수(가두기)한다.
다른 색 젤리는 통과할 수 없는 장애물이고, 캐처끼리도 통과할 수 없다.**

## 실행 방법

1. [Godot 4.4 이상](https://godotengine.org/download) 설치 (Standard 버전, .NET 불필요)
2. Godot 프로젝트 매니저 → **가져오기(Import)** → 이 폴더의 `project.godot` 선택
3. 에디터에서 **F5** (또는 우상단 ▶) 로 실행
4. 데스크톱에서는 마우스 드래그 = 터치 드래그 (터치 에뮬레이션 켜져 있음)

## 게임 규칙 (v0.3 코어 — 사용자 확정 룰)

- **캐처(구멍 블록)를 드래그**하면 격자 단위로 슬라이드
- 캐처가 칸에 도착하면 **같은 색 젤리가 구멍 안으로 들어간 뒤 흡수**
- **다른 색 젤리는 통과 불가** — 다른 색 캐처로 먼저 길을 뚫어야 함 (순서 퍼즐)
- **캐처끼리 통과 불가**, 벽(`#`) 통과 불가
- 캐처의 숫자는 **남은 수용량**. 일반 레벨에서는 모두 채우면 사라지고, 배출구 레벨에서는 `GO` 상태가 됨
- `GO` 블록은 젤리를 통과할 수 없으며 같은 색 화살표 배출구까지 옮겨 보드 밖으로 내보내야 함
- 배출구 레벨은 모든 젤리를 흡수하고 모든 블록을 배출해야 클리어. 제한시간 초과 시 실패
- 행동력은 최대 5개. L1~5는 무료이며 L6부터 입장 시 1개 예약 차감, 클리어 시 반환, 실패·포기 시 소모
- 행동력은 오프라인 시간을 포함해 10분마다 1개씩 회복되며, 1개가 생기는 즉시 재도전 가능
- 처음 달성한 별 단계에 따라 별가루를 1성 1개, 2성 2개, 3성 3개 지급. 최고 기록 이하 재클리어는 중복 지급하지 않음
- 시간 초과 시 별가루 20개로 현재 보드 상태를 유지하고 제한시간만 초기화해 이어할 수 있음
- 캐처 모양: 1×1, 2×1, 1×2, 3×1, 2×2, L자 2종 — 넓적한 캐처는 한 번에 여러 마리 흡수

## 젤리 아지트

- 타이틀 화면은 대표 젤리몬과 구출 주민이 생활하는 개인 방으로 구성
- 누적 별 15개와 60개에서 대표 젤리몬이 총 3단계로 성장
- 일반 폴리오미노 가구 20종과 클리어 기록 전용 업적 가구 10종 수집
- 꾸미기 모드에서 가구 드래그, 격자 스냅, 회전, 회수 및 자동 저장
- 각 챕터 첫 클리어 시 색상별 구출 주민 초대, 방에는 최대 5마리 표시
- 앨범에서 주민과 10개 업적 진행 상황 확인
- 촬영 모드에서 UI 없는 세로 이미지를 시스템 사진 폴더의 `JellyMon` 디렉터리에 PNG로 저장

| 대체 승리 조건 | 제한 이동 · 지정 색 순서 · 전담 호위로 목표 자체가 바뀜 |

## 관문 보스 (10레벨마다)

| 보스 | 규칙 | 요구되는 판단 |
|---|---|---|
| 👑 왕젤리 | 같은 색 블록으로 2~4번 두드려야 구조된다 | 같은 자리를 여러 번 오가는 왕복 동선 설계 |
| 🌀 분열 젤리 | 구조하는 순간 인접 칸으로 같은 색 미니 젤리가 흩어진다 | 담을 수용량과 빈칸을 미리 남겨 두기 |
| ⏳ 시간 도둑 | 살아 있는 동안 주기적으로 남은 시간을 훔치고, 구조 시 시간을 돌려준다 | 먼저 잡을지 나중에 잡을지 우선순위 결정 |

## 대체 승리 조건 (111레벨 이후)

| 조건 | 규칙 |
|---|---|
| 🎯 제한 이동 | 정해진 이동 횟수 안에 전원 구조. 끈끈이 바닥을 밟으면 이동 비용 2배 |
| 🔢 지정 순서 | 정해진 색 순서대로만 구조 가능. 차례가 아닌 색은 장애물이 된다 |
| 🛡 호위 | 표시된 호위 대상 젤리는 지정된 전담 블록만 구조할 수 있다 |

## 신규 기믹 (101레벨 이후)

| 기믹 | 해금 | 규칙 |
|---|---|---|
| 👻 유령 젤리 | L101 | 다른 색 블록이 그대로 통과할 수 있어 막힌 길이 열린다 |
| 🍯 끈끈이 바닥 | L131 | 밟으면 블록이 눈에 띄게 느려지고 제한 이동에서 2수를 소모한다 |
| ➤ 일방통행 타일 | L161 | 화살표와 같은 방향으로만 진입할 수 있어 동선이 크게 제한된다 |
| 💣 폭탄 젤리 | L191 | 구조하면 인접한 장벽이 부서져 새 길이 열린다 |

기존 기믹(❄얼음 L51 / ⛓순서 체인 L61 / ◆스위치 L71 / 🔑열쇠 L81)과 함께
101레벨 이후에는 해금된 기믹이 매 레벨 2~4개씩 결정적 규칙으로 조합된다.

### 가두기(흡수) 이펙트 구성
젤리 스쿼시 → 캐처 구멍 속으로 회전하며 빨려드는 트윈(0.16s) → 색상 방울 파티클 버스트 + 소용돌이 입자 + 충격파 링 → 캐처 "꿀꺽" 스쿼시 → 플로팅 점수 → 햅틱. 한 번에 3마리 이상 쓸어담으면 화면 셰이크.

## 레벨 구성 (500개 · 50챕터 × 10레벨)

- L1~4 — 조작과 색 장벽을 배우는 쉬운 튜토리얼
- L5~50 (챕터 1~5) — 다칸 캐처, 좁은 문, 링/체커 레이어, 불규칙 외곽
- L51~100 (챕터 6~10) — ❄얼음 → ⛓순서 → ◆스위치 → 🔑열쇠를 10레벨 단위로 학습하고 복합 관문으로 마무리
- L101~200 (챕터 11~20) — 👻유령 → 🍯끈끈이 → ➤일방통행 → 💣폭탄을 도입하고, 111레벨부터 대체 승리 조건이 순환 등장
- L201~500 (챕터 21~50) — 세로 한 칸이 넓어진 보드에서 해금된 8종 기믹과 3종 승리 조건, 3종 보스가 결정적 규칙으로 조합

5의 배수는 ★도전, 10의 배수는 ★★대도전 겸 **보스 관문**이다.
100레벨 이후에는 보드 밀도가 상한에 닿으므로, 난도 상승은 젤리 수가 아니라
기믹 조합·보스 규칙·승리 조건 변주가 담당한다.

홀 모양은 L1~4 튜토리얼 이후 테트리스의 7개 테트로미노를 기준으로 구성된다.

- L1~4: 조작 학습용 1×1, 2×1, 1×2
- L5~10: I·O 테트로미노
- L11~20: J·L 및 회전형 추가
- L21~30: T와 네 방향 회전형 추가
- L31~50: S·Z와 회전형까지 7종 전체 혼합
- 제한시간은 L5 90초부터 점차 줄어 L50에서 63초가 되어 제거 순서를 빠르게 판단해야 함
- 홀은 상·중·하단에 분산하고 젤리를 홀 주변 빈칸으로 재배치해 두 종류가 보드 전체에서 뒤섞임
- 재배치된 다른 색 젤리가 대형 홀의 이동 통로를 막아 올바른 제거 순서를 요구함
- L5부터 10종의 외곽 변형(계단·좌우 홈·중앙 홈·비대칭 모서리)을 레벨마다 순환 적용
- 큰 블록의 마지막 목표가 모서리에 고립되지 않도록 자동 젤리 재배치에서 외곽 셀을 제외
- L6부터 일부 레벨에 모양 봉인이 등장하며, 장벽을 열지 않아도 기본 클리어가 가능한 선택형 지름길로 구성
- L7부터 모양 봉인 레벨과 번갈아 색상별 젤리 배출구가 등장하며, 자동 풀이가 배출 경로까지 검증된 맵만 사용

레벨 선택 화면은 챕터별 10레벨을 묶은 세로 스크롤 맵이며, 이전 레벨을
클리어하면 다음 레벨이 열린다. 모든 레벨은 실행 시 행 길이, 캐처 시작점,
색상별 캐처 존재 여부와 실제 이동 충돌 기준 도달 가능성을 자동 검사한다.

개발용 빠른 레벨 검증:

```bash
# 전체 500레벨 구조·풀이 가능성 검증
godot --headless --path . -- --validate-levels

# 앞쪽 N개만 생성해 빠르게 반복 (생성기 수정 중 유용)
godot --headless --path . -- --validate-levels --gen-limit=210

# 생성기를 고친 뒤 assets/data/levels.json 재베이크
godot --headless --path . -- --bake-levels

# 보스 3종·승리 조건 3종·신규 기믹 4종 런타임 자동 플레이 검증
godot --headless --path . -- --validate-endgame
```

레벨 데이터는 `assets/data/levels.json`에 베이크되어 있고, 파일이 없거나
개수가 맞지 않으면 `Levels.gd`의 생성기가 실행 시 다시 만든다. 생성기는
모든 레벨에 대해 실제 이동 충돌 규칙(유령·일방통행·호위·색 순서·분열 보스
포함)으로 자동 풀이를 돌려, 클리어 불가능한 맵은 저장하지 않는다.

## 후속 확장 범위

- 특수 젤리: 무지개·풍선·돌젤리
- 바닥 타일: 포털·진흙
- 101레벨 이후 구간의 마일스톤 가구 보상 트랙 확장 (현재 L10~100만 지급)
- 코인 경제/상점 확장, 광고·IAP 네이티브 브리지
- BGM, 일시정지 팝업

## 폴더 구조

```
game/
├── project.godot        # Godot 4.4+, 720×1280 세로, 터치 에뮬레이션
├── scenes/Main.tscn     # 루트 씬 (나머지는 코드로 구성)
├── scripts/
│   ├── Main.gd          # 화면 전환/저장
│   ├── Game.gd          # 코어 룰 (캐처 이동/흡수/용량 제거)
│   ├── Catcher.gd  Jelly.gd  FX.gd  HUD.gd
│   ├── Levels.gd        # 500레벨 생성·검증 데이터 (보스/기믹/승리 조건 스케줄)
│   ├── Title.gd  Map.gd  AudioMgr.gd  SaveGame.gd  G.gd
├── assets/
│   ├── catchers/        # 캐처(구멍 블록) 스프라이트 (7모양×6색)
│   ├── jelly_*.png      # 젤리 + UI 아이콘
│   └── fonts/Jua-Regular.ttf  (OFL 라이선스, OFL.txt 동봉)
└── audio/               # 프로그래매틱 생성 효과음 (WAV)
```

에셋은 전부 자체 생성물이라 라이선스 문제 없음 (폰트는 SIL OFL).
