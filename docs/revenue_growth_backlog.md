# 젤리몬 매출·리텐션 개선 백로그

## 제품 방향

젤리몬의 차별점은 `잡아서 끝나는 퍼즐`이 아니라 `구조한 젤리몬을 순화하고 함께 생활하는 퍼즐`이다. 강제 광고와 자극적인 확률형 상품보다 주민 애착, 구조 원정, 꾸미기 자랑거리가 반복 방문과 구매를 만들도록 한다.

## P0 — 출시 기반

- [x] 플레이 퍼널 분석 이벤트 스키마와 로컬 버퍼
- [x] 경제·리텐션 주요 수치 JSON 분리
- [x] 대표 젤리몬 성장을 300별까지 확장
- [x] 주민 친밀도 10단계와 일일 획득 상한
- [ ] HIVE 로그인·광고·결제 네이티브 브리지
- [ ] 서버 영수증 검증과 구매 복원
- [ ] 크래시 리포트, 원격 설정, 이벤트 업로드 API
- [x] 100레벨 단위 강제 광고 관문 제거·선택형 보상 광고와 VIP 일일 지원으로 전환
- [x] 초반 50레벨 감정 아크·10개 시그니처 구조 장면·완료 연출 데이터화
- [x] 주민 친밀도·마을 복구를 시간/힌트/샤이니/첫 클리어 보너스에 연결
- [x] 익명 원격 분석 배치 업로드·오프라인 큐·베타 인게임 설문 기반 구현
- [x] 첫 챕터 홈 기능 순차 해금과 시각형 주민·추억 앨범
- [x] 홈·지도·퍼즐·보스·스토리 BGM과 일시정지/앱 전환 보호

## P1 — 핵심 재미와 반복 방문

- [x] 10레벨 단위 전용 보스 규칙 3종 (왕젤리 / 분열 / 시간 도둑, 110레벨부터 순환)
- [x] 지정 순서, 호위, 제한 이동 등 대체 승리 조건 (111레벨부터 순환)
- [x] 캠페인 500레벨 확장과 신규 기믹 4종 (유령 / 끈끈이 / 일방통행 / 폭탄)
- [x] 날짜별 순환 일일 고난도 구조 퍼즐
- [x] 매주 구성이 바뀌는 5스테이지 주간 구조 원정
- [x] 날짜별 주민 부탁·선호 가구 반응·친밀도 추억 대사
- [ ] 실패 원인별 힌트와 난이도 텔레메트리 대시보드
- [x] 101~300레벨 이야기·성장·마일스톤 가구 보상 트랙 확장
- [x] 후반 복합 힌트 2줄 압축·드래그 색상 포커스와 301~1000 장기 원정 서사

## P2 — 장기 성장과 수익화

- [x] 28일 무료/프리미엄 시즌 트랙과 한정 가구 보상
- [ ] 주민 추억 사진 컬렉션과 중복 교환
- [x] 초보자·챕터 돌파·아지트 꾸미기 상품 묶음과 가격 사다리
- [ ] 신규 방과 의상·액세서리 세트
- [x] 방문 코드 공유/미리보기와 주간 특별 구조 최고 기록 경계
- [ ] 팀 구조전은 D7 리텐션 검증 후 도입

## 출시 판단 지표

- 튜토리얼 완료율과 1·5·10레벨 도달률
- 레벨별 실패율, 평균 시도 수, 실패 이유, 이어하기율
- D1·D7·D30 리텐션
- 보상형 광고 제안/완료율
- 상점 노출→상품 선택→구매 성공 전환율
- 별가루 획득/소비 비율과 가구 구매까지 걸린 기간
- 주민 상호작용, 꾸미기, 앨범 사용자의 리텐션 차이

기능은 한꺼번에 출시하지 않는다. P0 계측을 먼저 배포하고 코호트 데이터로 P1 콘텐츠 우선순위와 보상량을 조정한다.
