## 3. 상품 공통 등록값

| 항목 | 입력 기준 |
|---|---|
| 상품 종류 | 단건 상품 / 일회성 제품(One-time product) |
| 기본 언어 | 한국어 — ko-KR |
| 구매 유형 | 구매(Buy) |
| 구매 옵션 ID | 옵션 입력이 필요한 화면에서는 각 상품에 `buy` 1개 사용 |
| 한국 판매 가격 | 아래 표의 KRW 가격 |
| 구매 수량 | 거래당 1개 |
| 자동 갱신 구독 | 사용하지 않음 |
| 대여·선주문·할인 오퍼 | 이번 등록에서 사용하지 않음 |
| 판매 상태 | 테스트에 사용할 상품과 구매 옵션 활성화 |

표의 반복 구매 여부는 **게임의 지급 정책**입니다. Google Play에 모두 단건 상품으로 등록합니다. 한국 최종 사용자 가격과 판매 지역을 저장 전에 확인하세요. 앱에는 Google Play가 반환하는 실제 표시 가격이 사용됩니다.
