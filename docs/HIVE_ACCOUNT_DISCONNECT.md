# Hive 계정 연결 해제

메인 화면의 메뉴에서 로그인 전에는 **계정 연결**, 로그인 후에는 **연결 해제** 버튼을 표시한다.

## 확인과 처리

- 연결 해제를 누르면 현재 계정 유형에 맞는 안내 팝업을 표시한다.
- `DELETE ACCOUNT`를 대문자와 공백까지 정확히 입력해야 실행할 수 있다. 앞뒤 공백도 허용하지 않는다.
- 게스트 계정은 Hive `AuthV4.playerDelete`를 호출한다. 기존 게스트 계정은 삭제되므로 다시 로그인할 수 없다.
- Google 등 연결 계정은 Hive `AuthV4.signOut`을 호출한다. 외부 제공자의 계정을 삭제하거나 연결을 끊는 기능은 아니다.
- SDK 성공 응답을 받은 뒤에만 앱의 로그인 정보를 지운다. 실패하면 기존 로그인 상태를 유지하고 재시도할 수 있다.
- 처리 중 중복 요청을 차단하고 진행 중인 클라우드 저장 및 랭킹 인증 응답을 무효화한다.
- 성공하면 버튼이 **계정 연결**로 돌아온다. Android 설정에 수동 연결 해제 상태를 저장하여 재실행 시 자동 로그인을 막는다. 사용자가 다시 계정 연결을 선택하면 로그인할 수 있다.

## 데이터 범위

연결 해제 성공 후 기기의 게임 저장을 새 `SaveGame` 기본값으로 덮어쓴다. 진행도, 클리어 시간/별 3개 달성 시각, 재화, 가구와 배치, 방 테마, 주민, 출석, 구매/보상 수령 기록, 닉네임, 튜토리얼, 설정, 이벤트 진행 및 기록 소유자 정보가 초기화된다. 로컬 클라우드/랭킹 대체 파일, 앱 내부 사진과 로컬 분석 이벤트·전송 대기도 지운다. 화면과 저장 서비스 참조를 새 저장으로 갱신하고 처음 시작 화면을 표시한다. 이전 저장 객체는 저장을 비활성화하여 늦은 콜백이 이전 데이터를 다시 기록하지 못하게 한다.

Hive 클라우드와 별도 랭킹 서버의 기록은 삭제하지 않는다. 연결 해제가 실패하면 기기 데이터도 유지한다. 기기 밖으로 내보낸 사진은 삭제하지 않는다. Android의 수동 연결 해제 설정은 유지하여 자동 로그인을 방지한다.

## 검증

- `tools/verify_account_reset.tscn`: 정확한 확인 문구, 중복 실행 차단, 실패 후 재시도.
- `tools/verify_account_disconnect.tscn`: SDK 모의 응답으로 성공/실패, 게스트 삭제 허용, 로그인 상태 정리 검증.
- `tools/verify_disconnect_ui.tscn`: 연결 상태에 따른 버튼 전환, 게스트 안내 팝업, 확인 입력, 실패 시 데이터 보존, 성공 후 전체 로컬 초기화, 저장 서비스 참조 갱신과 파일 재로딩 검증.

실기기에서는 기존 계정을 보존하기 위해 실제 계정 삭제를 실행하지 않고 버튼 및 확인 팝업까지 확인한다.
