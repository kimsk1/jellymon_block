# 디버그 APK 테스트 기간

Godot Android 내보내기에서 `Export With Debug`를 켜고 APK를 만들면 내보내기 시작 시각과 한 달 뒤 만료 시각이 APK 내부 `res://debug_build_expiry.json`에 포함됩니다. 기존 HiveBridge 내보내기 플러그인이 이 파일을 생성합니다. 플러그인은 활성 상태를 유지해야 합니다.

달력상 다음 달 같은 날짜·시각(UTC)을 사용하며, 다음 달에 해당 날짜가 없으면 말일로 맞춥니다. 최초 실행, 재설치, 게임 저장 초기화는 같은 APK의 만료일을 연장하지 않습니다. 새 APK를 빌드하면 새 만료일이 부여됩니다. 이미 배포된 APK에는 소급 적용되지 않습니다.

실행 시, 실행 중 매초, 백그라운드 복귀 시 확인합니다. 만료되면 게임을 일시 정지하고 새 테스트 APK 설치 안내와 종료 버튼을 표시합니다. 디버그 APK에서 메타데이터가 누락된 경우에도 실행을 차단합니다.

정식 Android 빌드, AAB, iOS, 에디터와 데스크톱은 제한하지 않습니다. 이 제한은 기기 시간을 사용하므로 기기 시계 조작이나 APK 변조에 대한 강제 보안 수단은 아닙니다.

검증: `Godot --headless --path . --script tools/tests/debug_build_expiry_test.gd`
