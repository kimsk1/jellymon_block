# 현지화 적용 범위와 검증 (2026-09-11)

한국어 UI 하드코딩을 표시 시점 번역으로 연결하고 영어 카탈로그를 확장했다. 한국어와 영어는 각각 2,797개 키다. 일본어·중국어 간체·중국어 번체·프랑스어·독일어·스페인어는 각각 자체 번역 152개와 영어 대체 2,645개를 사용한다. **8개 언어 전체 번역 완료를 의미하지 않는다.** 해외 출시 전 각 언어의 영어 대체 문구에 대한 번역·교정이 남아 있다.

## 변경

- `Localization.gd`: 영어 기본 카탈로그 위에 선택 언어를 덮어쓰므로 번역 누락 때문에 한국어 원문이 표시되지 않도록 처리.
- `LocalizedText.gd`: 저장된 한국어 이름·합성 문구를 표시할 때 번역. 원본 저장 데이터와 게임 규칙용 ID를 변경하지 않는다. 반복 표시 문구는 제한된 캐시에 저장한다.
- 홈, 메뉴, 상점, 출석, 미션, 도감, 앨범, 주민, 맵, 퍼즐 HUD, 랭킹, 클라우드 선택과 오류 안내 등을 연결했다.
- 1,000개 레벨 이름·힌트와 카탈로그 설명을 포함한다. 키 수에는 조합된 레벨 문구가 포함된다.
- 플레이어 입력 닉네임은 자동 번역을 끄고 원문을 보존한다. 클라우드 선택은 번역된 버튼 문자열 대신 고정 action ID를 사용한다.
- 긴 상품명이 줄바꿈되도록 하고 구매 버튼에는 말줄임을 적용했다.
- 기존 `story.json`의 별도 다국어 대화 컨텍스트는 유지한다.

## 검증

```sh
python3 tools/verify_localization.py
Godot --headless --path . --validate-localization
Godot --headless --path . --quit-after 2400 res://tools/verify_ui_localization.tscn
```

정적 검사: 키·자리표시자·외국어 값의 한국어 노출·데이터 카탈로그 커버리지 오류 0. Godot 카탈로그 검사: 8개 언어 오류 0. 실제 UI 노드 검사: 한국어 외 7개 언어의 주요 화면·팝업·대표 레벨과 클라우드 선택 신호 오류 0. 사용자 닉네임과 저장 데이터 원문 보존도 확인했다. 영어 메뉴·상점의 실제 렌더링을 확인하고 상품 행의 화면 밖 넘침을 수정했다.

macOS 샌드박스 headless 실행 시 시스템 CA 인증서 접근 오류가 별도로 출력되지만 위 현지화 검사는 통과했다. 결제 서버·실기기 네이티브 오류의 모든 조합을 실제 결제로 재현한 결과는 아니다.

## 유지보수

새로운 사용자 표시 문구는 먼저 영어·한국어 JSON에 같은 키로 등록하고 표시할 때 번역한다. 형식 문자열은 번역 후 값을 삽입한다. 신규 데이터 문구도 정적 검사 대상이다. ID, 파일 경로, 닉네임 등 사용자 입력을 번역하지 않는다. 각 언어에서 자연스러운 표현과 긴 문장의 실기기 배치는 별도 교정이 필요하다.
