# 홈 빈 방 테마와 A안 메뉴 배치

2026-09-08 구현. 초기 홈 시안 중 A·B·D를 정면 2D 방 배경으로 적용한다. 메뉴 배치는 세 테마 모두 A안으로 통일한다.

## 이용 흐름

- 새 사용자는 **B · 민트 아침**의 빈 방으로 시작한다. 시작 가구 4종은 보관함에 지급한다.
- 상단 **방 테마**를 누르면 A · 햇살 크림, B · 민트 아침, D · 달빛 아지트의 이미지와 선택 버튼을 표시한다. 세 테마는 무료이며 처음부터 선택할 수 있다.
- **꾸미기**에서는 가구 배치·회전·치우기와 테마 변경을 할 수 있다. 기존 꾸미기 해금 시점은 유지한다.
- 테마를 바꿔도 소유 가구, 배치 좌표, 회전, 주민과 진행도는 유지한다.
- 마지막 가구를 치워 빈 방으로 저장해도 재실행 시 가구가 다시 채워지지 않는다.
- 기존 사용자의 배치는 유지하고, 저장된 테마가 없거나 알 수 없는 값이면 B를 적용한다.

## 화면 구성

상단 프로필·성장·재화, 그 아래 방 테마·구조·선물 바로가기, 중앙 방, 하단 레벨 정보와 가로로 넓은 모험 시작 버튼, 지도·꾸미기·상점·메뉴의 순서다. 메뉴는 크림 배경과 코랄 강조색을 공통으로 사용한다.

배경에는 벽·바닥·창문·커튼만 포함한다. 러그·화분·조명·가구·캐릭터는 배경에 구워 넣지 않는다. 기존 가구 렌더링과 주민 애니메이션은 별도 레이어로 유지한다.

## 파일과 좌표

- `assets/backgrounds/rooms/room_a.png`, `room_b.png`, `room_d.png`: 실제 실행 리소스. 내장 image_gen 도구로 제작했다.
- `scripts/RoomData.gd`: 테마 ID·이름·이미지 경로·벽/바닥 분할 비율, 기본 B 설정.
- `scripts/RoomBackdrop.gd`: 테마 배경과 편집 격자. 생성 이미지마다 다른 벽 높이를 보정해 공통 바닥 시작점에 맞춘다.
- `scripts/Title.gd`: A안 메뉴 구성, 미리보기와 테마 선택, 꾸미기 연결.
- `scripts/SaveGame.gd`: `room_theme_id` 저장과 진행 데이터 스냅샷, 빈 배열을 유효한 방 배치로 보존.
- `assets/localization/*.json`: 새 테마 관련 문구 8개 언어.

배치 좌표는 기존 `8×6`, 셀 `76`, 원점 `(56,390)`, 화면 Y 오프셋 `50`을 유지한다. 배경의 바닥 시작점도 이 좌표에 맞춘다. 사진 모드의 기존 Y 이동을 그대로 적용한다.

## 검증

```sh
/Applications/Godot_mono.app/Contents/MacOS/Godot --headless --path . res://tools/verify_home_themes.tscn -- --shots
```

새 저장의 B·빈 방, 시작 가구 소유, 테마 변경 후 좌표 보존, 실제 저장/재로드, 마지막 가구 제거, 기존 배치 호환, 잘못된 테마 값, 진행 스냅샷, 실제 선택 버튼, 꾸미기에서 배치와 테마 변경, 세로로 긴 화면과 태블릿 안전 여백을 검사한다. 검사는 고유한 임시 저장 경로를 사용하며 실제 사용자 저장을 수정하지 않는다.

`--headless`를 빼고 `--render-home-themes`를 추가하면 실제 렌더러로 `output/home-themes/`에 홈 3종·선택 팝업·꾸미기 화면을 저장한다. 같은 폴더에 빈 방 원본 3종과 생성 프롬프트도 있다. 해당 폴더는 `.gdignore`로 실행 리소스 수집에서 제외한다.

## B 테마 전용 UI (2026-09-08)

B는 배경과 함께 UI 색상·아이콘도 전환한다.

- 주요 버튼과 성장/진행 막대: 민트 `#43bfb0`, 눌림 `#329e91`.
- 하단 메뉴: 세이지 `#557b68`의 지도 핀, 소파, 바구니, 세 줄 메뉴 아이콘.
- 상단 재화: 컬러 별·하트. 구조와 출석 버튼: 구명환·선물 상자.
- 모험 시작 버튼: 민트 테두리와 잎 장식.
- 상점·지도·게임 HUD·팝업의 공통 주요 버튼에도 선택된 테마의 강조색을 사용한다.

`ArtDirection.set_room_theme`와 `primary_color`가 테마 색상을 관리한다. 앱 시작 시 저장된 테마를 적용하고, 홈에서 변경할 때 UI를 다시 구성한다. 홈 화면 노드와 가구 노드는 유지하므로 편집 중 배치·선택 상태를 보존한다. 아이콘은 기존 `HomeNavIcon.gd`에 B 전용 도형을 추가해 플랫폼별 이모지 차이 없이 표시한다.

A의 기존 코랄 버튼과 아이콘은 유지한다. B를 기본으로 사용하는 새 저장에도 전용 UI가 바로 적용된다.

검증: `tools/verify_home_theme_ui.tscn`. A/B/D 화면과 즉시 전환, 4개 하단 아이콘, 성장 막대, 팝업 주요 버튼, 저장·편집 상태를 확인한다.

## D 테마 전용 UI (2026-09-08)

D는 밤의 방 배경에 맞춰 화면과 팝업 전체의 팔레트를 전환한다.

- 패널: 짙은 자주색 `#463044`, 테두리 `#75566d`.
- 글자와 하단 메뉴 아이콘: 크림 `#f6e3bd`. 지도 발바닥, 의자, 별 장바구니, 세 줄 메뉴를 사용한다.
- 주요 버튼: 금빛 `#efb24f`, 눌림 `#d99a3f`. 버튼 글자는 짙은 갈색으로 대비를 확보한다.
- 성장 막대: 분홍빛 `#c1779c`.
- 재화와 바로가기: 컬러 별·하트·구명환, 금빛 선물 상자와 자주색 리본.
- 상점, 설정, 지도, 스토리, 게임 HUD 및 결과/실패 등 팝업도 같은 테마 토큰을 사용한다.

B 기본 설정, 기존 메뉴 배치, 빈 방과 가구 편집 기능을 유지한다. 선택 즉시 UI를 갱신하며 편집 중 테마를 바꿔도 배치와 선택을 보존한다.

검증: `tools/verify_night_theme_ui.tscn`은 A/B/D 전환, 아이콘, 성장 막대, 주요 버튼, 저장·편집 상태와 화면 비율을 확인한다. `tools/verify_ui_theme.tscn -- --shots --night-theme`은 D 테마의 25개 화면과 팝업을 확인한다.
