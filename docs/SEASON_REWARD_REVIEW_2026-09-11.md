기존 저장 데이터의 당일 부탁은 삭제하거나 초기화하지 않는다. 이미 생성된 중복 부탁을 소급 재작성하지 않으며 다음 날 새 생성부터 중복 방지가 적용된다. 시즌 만료 전에 생성된 당일 부탁도 보존한다.

## 검증

`tools/verify_season_rewards.tscn`을 Godot 4.7 headless로 실행했다. 별도의 존재하지 않는 저장 경로와 `persistence_enabled=false`를 사용해 실제 사용자 저장과 격리했다.

```sh
"$GODOT_BIN" --headless --path . --log-file /tmp/jellymon-season-check.log tools/verify_season_rewards.tscn
python3 tools/verify_localization.py
```

- L10 상점의 실제 VIP 버튼 신호로 별가루 8·시간 젤리 1 지급, 중복 차단.
- L10 프리미엄 구매 상태에서 생활 화면과 Lv1 버튼 접근, XP 0에서 별가루 40 지급, 수령 후 버튼 비활성화.
- 비구매자·미달성 단계·존재하지 않는 무료 Lv1 수령 거절.
- 데이터에 정의된 보상 9종 표시 및 수령, 각 보상 중복 수령 차단.
- 주민 3명·6명에서 무료 부탁 2개와 프리미엄 3개의 ID 중복 없음.
- 구매 당일 추가 부탁 생성 시 기존 진행도·수령 상태 보존, 반복 갱신 시 추가 지급 없음.
- 이전 시즌 만료 후 새 날짜에 무료 부탁 2개 생성.
- 시즌 회귀 검사 `failures=0`, 종료 코드 0. 최종 실행에서 스크립트 오류·리소스 누수 없음.
- 현지화 정적 검사 `failures=0`. 새 번역 문구를 추가하지 않고 기존 문구 사용.

이번 검증은 코드와 headless UI 동작 검사다. 테스트폰 APK 재빌드·설치는 수행하지 않았다.

## 별도로 남은 확인 사항

기존 출시 보고서의 “소소한 버그”를 전부 해결했다고 판단하지 않는다.

| 항목 | 이번 코드 확인 | 상태 |
|---|---|---|
| 제한 이동 실패 후 이어하기 | `_continue_with_stardust()`가 시간만 복원하고 소진된 이동 횟수는 복원하지 않음 | 미수정. 이동 추가량 또는 이어하기 제한 정책과 함께 수정 필요 |
| 완벽 구조 실패 후 이어하기 | 이어하기는 1성으로 제한되지만 완벽 구조는 2성 이상 요구 | 미수정. 보상 없는 재실패를 막는 처리 필요 |
| 환영 공지의 모험 개수 | `assets/data/live_messages.json`에 여전히 100개로 표기 | 미수정. 실제 1,000개에 맞춘 문구와 번역 수정 필요 |
| 초록 주민 이름 | 프로필은 새롬, 시나리오 manifest는 새싹 | 미수정. 표준 이름 확정 후 대사·번역 일괄 정합성 검증 필요 |
