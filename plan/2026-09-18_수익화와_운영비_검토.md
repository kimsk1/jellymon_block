# 젤리몬 수익화와 운영비 검토

기준일: 2026-09-18. 프로젝트 소스와 공개 요금표 기준이며 실제 매출/광고 콘솔 실적은 확인하지 않았다. 매출 수치는 가정별 계산이지 예상 매출 보장이 아니다.

## 판단

수익화 기반은 있으나 광고의 반복 시청 동기와 반복 결제 동기가 약하다. 서버 자체는 저렴하게 시작할 수 있지만 Hive 인증 호출량과 콘텐츠 운영 인건비가 주요 변수다.

## 현재 구조의 문제

| 항목 | 구현 및 영향 |
|---|---|
| 보상 광고 | 새로운 별 보상에 대한 2배 받기에 집중. 기존 별 재클리어에서는 보상 버튼이 없어 시청 기회 감소 |
| 이어하기 | 별가루 20개. 실패 직후 광고 선택지 없음 |
| 하트 | 10분 회복, 클리어 반환으로 하트 구매 필요성 낮음 |
| 무료 재화 | 첫 주 출석 별가루 310개, 일일 미션 15개 등으로 소량 광고 보상/결제 매력 약화 가능 |
| VIP | 3,000원 영구 구매로 매일 별가루 8개와 시간 부스터 1개. 30일 별가루 240개를 지급하여 50개/1,000원 상품의 반복 구매를 대체할 가능성 |
| 시즌 | 6,500원, 28일 주기. 진행도와 구매 상태 초기화 후에도 보상표는 동일하며 보유 가구는 중복 추가하지 않아 재구매 가치 약화 |

일반 상품 가격은 assets/data/item.json 기준이며 플랫폼 실판매 가격은 다를 수 있다.

## 광고 개선 방향

선택형 광고를 유지하고 보상이 필요한 순간을 늘린다. 보상형 광고 2~4회/DAU를 초기 실험 목표로 삼되 재방문율과 동시 평가한다. 검증된 최적값은 아니다.

| 위치 | 보상 | 실험 제한 |
|---|---|---|
| 시간 초과 | 추가 시간 이어하기 | 한 판 1회 |
| 하트 부족 | 하트 1개 | 하루 3회 |
| 부스터 부족 | 이번 판 전용 부스터 효과 | 하루 2회 |
| 아지트 | 소량 별가루 또는 꾸미기 재료 | 하루 1회 |

무료 출석 보상에 광고를 강제하지 않는다. 구매 동선은 첫 구매 팩, 꾸미기 전용 상품, 시즌별 새로운 패스를 중심으로 설계한다. 기존 VIP 구매 혜택은 보존한다.

## 광고 매출 시나리오

DAU 1,000명, 30일. 광고 횟수는 전체 DAU로 나눈 실제 노출수이며 요청수가 아니다.

| 가정 | 광고/인/일 | eCPM 가정 | 월 광고 수익 | Adiz 7% 차감 후 |
|---|---:|---:|---:|---:|
| 낮음 | 0.5 | 3,000원 | 45,000원 | 41,850원 |
| 중간 | 2 | 7,000원 | 420,000원 | 390,600원 |
| 높음 | 4 | 12,000원 | 1,440,000원 | 1,339,200원 |

eCPM은 1,000회 노출당 수익. 위 단가는 시장 평균이 아닌 계산 가정이다. 국가/OS/공급량에 따라 달라진다. 정산 수익에 Adiz 수수료가 이미 반영되면 중복 차감하지 않는다.

계산: DAU × 광고/인/일 × 30 ÷ 1,000 × eCPM.

결제 예시: MAU 5,000명 × 결제율 1% × 월 결제자 평균 6,000원 = 월 300,000원. 세금/환불/스토어 수수료 전이며 실적 예측은 아니다.

## 운영비

플레이는 기기에서 처리하며 서버는 Node.js/SQLite 단일 인스턴스의 랭킹/결제 검증 중심이다. DB 백업과 복구가 필수이며 현재 SQLite 구조를 그대로 여러 인스턴스로 복제하면 안 된다.

AWS Lightsail Linux 2GB 월 $12, 4GB 월 $24를 시작 가격 참고로 사용한다. 특정 DAU 처리 능력을 보장하지 않으며 부하 검증이 필요하다.

Hive 공개 요금:
- 인증: 월 30,000회 무료, 초과 $0.002/회
- 결제: 월 1,000회 무료, 초과 $0.04/회
- 랭킹: 월 15,000회 무료, 초과 $0.00004/회
- Adiz: 광고 수익 7%

계약 조건/과금 대상 API 범위는 실제 콘솔에서 확인해야 한다. 서버는 랭킹 기록/결제 요청마다 Hive 인증을 요청하여 구매 한 번에 여러 인증이 발생할 수 있다.

예산용 환율 1달러=1,400원, 과금 대상 인증 2회/DAU/일, 랭킹 5회/DAU/일, 30일 가정:

| DAU | 서버/백업/모니터링 예산 | Hive 인증/랭킹 | 월 합계 |
|---:|---:|---:|---:|
| 100 | 3만~7만원 | 무료 범위 | 3만~7만원 |
| 1,000 | 5만~12만원 | 약 9.2만원 | 14만~21만원 |
| 10,000 | 15만~40만원 | 약 167.9만원 | 183만~208만원 |

부가세, 결제 API 초과료, 광고 수수료, 저장량 초과, 개발자 등록비, 인건비, 마케팅비 별도. 서버 예산은 추정이며 처리량 검증 결과가 아니다.

인증 5회/DAU/일이면 DAU 1,000명 기준 인증료가 월 8.4만원에서 33.6만원으로 증가한다. 불필요한 호출/재시도를 줄이되 인증을 생략해서는 안 된다.

추가 비용:
- Apple 개발자 연 $99, 지역 결제액 다름.
- Apple/Google은 관련 프로그램 가입 및 자격 충족 시 결제 수수료 15% 가능.
- 운영 20~40시간/월 × 시간당 3만원 가정 = 60만~120만원. 시장 견적이 아닌 작업시간 예산.
- 이용자 확보 광고비 별도. 이용자 생애 순수익이 유입 비용을 초과하는지 검증 필요.

## 출시 전 조건

1. Android/iOS test_ads=true, zone=sandbox를 운영 빌드와 분리한다.
2. ngrok 개발 서버를 정식 도메인/상시 운영 서버로 전환하고 백업 복구 검증한다.
3. analytics_remote.json의 비활성 분석 수집을 연결한다.
4. 결제부터 검증/지급/재접속/복구까지 실기기로 검증한다.

우선순위: 운영 환경과 결제 안정화 → 분석 연결 → 광고 위치 확대 → VIP/시즌 경제 조정 → 소규모 출시 지표 확인.
