# 선택형 보상 광고 구현 기록

## 적용

| 위치 | 효과 | 제한 |
|---|---|---|
| 시간 초과 실패창 | 현재 보드에서 30초 이어하기 | 별가루 이어하기와 합쳐 한 판 1회. 이동 횟수 초과는 제외 |
| 지도 하트 부족창 | 하트 +1 | 하루 3회 |
| 시간 부스터 재고 0 버튼 | 현재 판 시간 +15초 | 하루 2회. 영구 인벤토리 지급 없음. 맨손 구조 제외 |
| 아지트 선물/출석창 | 별가루 +5 | 하루 1회. 무료 출석과 독립 |

부스터 광고는 효과가 항상 명확한 시간 부스터부터 적용했다. 나침반/얼음/공간/구조 부스터는 해당 보드에서 효과가 없을 수 있어 광고 대상을 확장하지 않았다. 이후 확장 시 적용 가능성 사전 판정과 보상 보존 정책이 필요하다.

- 보상 확인창에서 직접 동의해야 광고 요청.
- 광고 준비/재생 실패/취소 시 횟수와 재화 소모 없음, 다시 시도 가능.
- 중복 클릭 및 중복 완료 콜백 차단.
- 시간 부스터 확인/광고 중 플레이 타이머 정지, 취소 후 재개.
- 일일 횟수는 기기 저장에 보존. 이전 날짜의 클라우드 저장 복구가 횟수를 되돌리지 않도록 클라우드 대상에서 제외.
- 현재 제한은 기기 로컬 날짜 기준이다. 재설치/계정 초기화/기기 날짜 변조/다른 기기까지 막는 서버 검증은 별도 출시 과제다.
- VIP 기존 혜택 및 clear_reward_double 하루 1회 스킵 유지. 신규 위치는 일반 선택형 광고와 동일.
- 기존 rewarded_ad_offer/result 이벤트에 placement를 구분하여 기록. 원격 분석 업로드 및 운영 광고 전환은 별도 과제.

## 검증

1. tools/tests/rewarded_placements_test.tscn: 중복 클릭/콜백, 실패 후 재시도, 하루 제한, 날짜 전환/역행, 재시작 시 횟수 유지, 임시 부스터의 재고 불변 통과.
2. tools/tests/rewarded_flow_test.tscn: 실제 홈/지도/게임 버튼 연결, 시간 부스터 취소와 시간 정지, 보상 지급, 실패창 광고 이어하기, 광고 후 유료 재이어하기 차단 통과.
3. tools/verify_season_rewards.tscn: 기존 VIP/시즌 보상 회귀 검사 failures=0.
4. 414×900 실제 OpenGL 렌더러에서 확인창 배치 및 전체 테스트 흐름 통과.
5. git diff --check 통과.

검증은 데스크톱 광고 모의 완료 경로를 사용했다. Android/iOS의 실제 광고 SDK/네트워크에서 시청/취소/백그라운드 복귀/재고 없음 테스트는 출시 전 필요하다. APK 재빌드/기기 설치는 이번 작업에 포함하지 않았다.
