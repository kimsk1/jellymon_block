# VIP 개선안: 기존 권리 보존과 신규 상품 분리

상태: 2026-09-18 코드 반영 완료. 기존 SKU, 지급량, 구매 권리는 변경하지 않았다.

반영 내용:
- `remove_ads`는 `legacy`/`sale_ended`로 표시해 기존 구매자에게만 상점에 노출. 지급·복원·하루 1회 클리어 2배 스킵은 그대로 유지.
- 신규 비소모성 `supporter_pack`(₩3,900, `jellymon.pack.supporter`): 후원 배지, 후원 명패, 추억 액자 한정 가구 2종. 매일 지급과 광고 스킵 없음.
- 시즌 프리미엄(`season_heart_star_pass`)에 `daily_support`(별가루 8 + 시간 젤리 1, 시즌 기간 한정)와 `clear_reward_ad_multiplier: 3`(광고 시청 시 3배) 추가. 시즌이 끝나면 자동 중단.
- 홈 화면에 "오늘의 구조 지원" 버튼을 추가해 상점 해금(L10)부터 VIP·시즌 지원을 바로 수령. 상점과 시즌 생활 팝업에도 각각 버튼 표시.
- 스토어 콘솔에 `jellymon.pack.supporter` 등록이 필요하며, `jellymon.remove_ads`는 복원을 위해 활성 유지.


## 핵심 판단

영구 3,000원에 매일 재화를 지급하는 현재 상품은 장기 이용자에게 유리하지만 재화 판매와 광고 수익을 계속 대체한다. 강제 광고가 없는 게임에서 remove_ads라는 내부 상품 ID를 근거로 '모든 광고 제거'를 약속하면 실제 혜택과도 불일치한다. 기존 상품은 현재 설명대로 보존하고 신규 판매 상품을 분리하는 것이 낫다.

## 권장안

### 1. 기존 VIP는 레거시 권리로 영구 유지

- 매일 별가루 8개/시간 부스터 1개, 클리어 2배 광고 하루 1회 즉시 완료, 배지/명패 그대로 유지.
- 영수증 복구 및 재설치에도 권리 유지. 신규 상품으로 강제 전환하지 않음.
- 새 상품 출시 시 기존 VIP의 신규 판매 중단은 별도 운영 결정. SKU 삭제/재사용/소모성 변경 금지.
- 기존 광고 스킵 혜택을 새 광고 위치 전체로 자동 확대하지 않음. 현재 약속한 clear_reward_double 위치만 적용.

### 2. 신규 영구 상품은 '구조대 후원 팩'으로 설계

- 비소모성 별도 SKU. 예시 가격 3,000~4,500원은 실험 제안이며 확정 아님.
- 구매 즉시 한정 움직이는 가구, 프로필 장식, 촬영 프레임 등 영구 소장 가치 제공.
- 매일 무기한 재화 지급과 무제한 광고 스킵은 포함하지 않음.
- 한 번의 후원으로 수집 욕구를 충족하고 반복 수익은 시즌으로 분리.
- 기존 꾸미기 팩과 보상이 겹치면 합치거나 차별화. 상품 수만 늘리지 않음.

### 3. 반복 매출은 28일 시즌 프리미엄 하나에 집중

- 이미 있는 6,500원 패스를 개선. 별도 월정액 VIP까지 동시에 추가하지 않음.
- 시즌마다 새 가구 세트/방 분위기/주민 반응/사진 장식 중 명확한 신규 소장 가치 제공.
- 구매 전 이미 달성한 보상, 남은 기간, 전체 프리미엄 보상을 공개.
- 시즌 종료 직전 구매에는 남은 기간을 명확하게 표시하고 달성 보상 소급 수령 보장.
- 동일 가구 반복 보상 금지. 중복 발생 시 대체 보상 규칙을 사전에 공개.
- 초기에는 광고 스킵 추가 없이 실험. 필요하면 '하루 클리어 보상 1회 자동 수령' 같은 제한형 혜택만 검토.
- 자동 갱신 없는 현행 방식 유지. 구독으로 바꾸려면 신규 계약/스토어 설정/명확한 동의 설계 필요.

## 대안 비교

| 방식 | 장점 | 비용/위험 | 판단 |
|---|---|---|---|
| 영구 VIP 가격만 인상 | 구현 간단 | 무기한 재화 공급 문제 유지, 기존자와 신규자 격차 | 비권장 |
| 영구 VIP 지급량 축소 | 경제 조정 쉬움 | 기존 구매 약속 훼손 | 기존자 적용 금지 |
| 별도 월정액 VIP 신설 | 반복 결제 가능 | 시즌 패스와 중복, 가격/권리 이해 어려움 | 현재 보류 |
| 영구 소장 팩 + 새 시즌 콘텐츠 | 혜택 명확, 콘텐츠 기반 반복 구매 | 매 시즌 제작/QA 비용 발생 | 권장 |

## 경제 검증

광고 스킵의 예상 월 기회비용 = 실제 대체 노출수 × 해당 국가/OS eCPM ÷ 1,000 × 광고 정산 비율.
'하루 1회 제공'이 반드시 30회 광고 손실은 아니다. 구매자의 실제 기존 광고 이용량으로 비교한다.

재화 지급은 구매자 매출만 볼 것이 아니라 별가루 소비처별 잔고 변화, 일반 상품 재구매율, 무료 이용자와 구매자 진행 속도, 광고 참여율을 같이 측정한다. 더 많이 지급하는 것보다 갖고 싶은 꾸미기 콘텐츠를 공급하는 것이 핵심이다.

## 검증/출시 조건

- 기존 구매자/미구매자를 분리하여 제안 상품 노출 테스트.
- KPI: 신규 결제 전환, 28일 재구매, 총 순수익/DAU, 광고 순수익/DAU, D7/D30 재방문, 환불/문의.
- 단순 구매율 상승만으로 승리 판단 금지. 광고 감소와 콘텐츠 제작비를 포함.
- 영구 권리와 시즌 기간은 서버 영수증/권리로 검증. 기기 날짜 의존 혜택은 변조 대응 별도 과제.
- 할인/가격 실험 전 실제 스토어 가격과 지역별 지급 가치 확인.
- 충분한 샘플/최소 두 시즌의 재구매 관찰 전 매출 향상 단정 금지.
